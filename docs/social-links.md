# Social links

The home and contact pages share the same social buttons. Configure verified HTTPS profile URLs using SOCIAL_FACEBOOK, SOCIAL_TIKTOK, SOCIAL_INSTAGRAM, and SOCIAL_YOUTUBE in your hosting environment.

YouTube defaults to https://www.youtube.com/@SanghaboPahasara. Set SOCIAL_YOUTUBE to override this channel URL and redeploy. Do not commit credentials or live environment files.
